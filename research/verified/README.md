# verified調査の管理ルール

## 位置づけ

`research/verified/` は、統括秘書の検証ゲートを通過した外部情報の正本保存先。保存されているだけで永久に利用可能、法的に正しい、公開承認済みという意味ではない。

## 必須ルール

1. 公式サイト、公式ドキュメント、公式発表など一次情報を優先する。
2. 調査日を `YYYY-MM-DD` で記録する。
3. 第三者が再確認できる参照URLまたは資料名を記録する。
4. 対象サービス、対象規約、プラン、地域、対象バージョンを記録する。
5. 原文引用と調査担当による要約を明確に分ける。
6. 法律、著作権、規約について法的判断を断定しない。
7. 料金、規約、商用利用、製品仕様には再確認期限を設定する。
8. 再確認期限切れ、更新日不明、アクセス不能の情報を現行情報として使用しない。
9. 確認できない情報、SNSや個人ブログだけの重要主張、出典不明情報をverified扱いしない。
10. 外部公開可能な要約と、判断過程・不確実性を含む内部メモを分離する。

## verifiedへの移行条件

- 重要な主張から情報源へ到達できる
- URLまたは資料へアクセスできる
- 公開日・更新日と調査日が記録されている
- 引用、要約、推測、注意事項が分離されている
- 再確認期限と期限切れ時の扱いがある
- 個人・顧客・機密情報を含まない
- 統括秘書または指定確認担当が `verified` と記録している

## 状態

- `verified・有効`: 検証済みで再確認期限内
- `verified・要再確認`: 期限間近、情報変更の兆候、条件不足
- `期限切れ`: 公開用原稿では使用禁止。再調査が必要
- `失効`: 情報源が置換、撤回、アクセス不能、誤り判明

## 各担当の利用

- 企画担当: 発信テーマ、使用可能な事実、追加調査を整理
- ライター: `verified・有効` の公開用要約・使用可能な主張だけを使用
- SEO担当: 根拠が必要な主張と外部リンク候補を確認
- 編集・校正担当: 断定、引用、数値と情報源の対応、期限を確認
- 統括秘書: 有効性、再確認期限、公開可否を最終確認

FRAMEPACT自身の料金、納期、修正条件、実績などは `business/framepact-service-facts.md` と `business/public-experience-facts.md` を参照する。
