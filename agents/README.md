# FRAMEPACT AIチーム — 17の役割定義

更新日: 2026-11-02。17役の定義を維持し、グロース・SEO・よっしーAIを連携する本人承認済みの日次改善を追加する。名簿の正本は [team-register.json](team-register.json)。これは役割プロンプトの構成であり、17個の独立したAIや常駐タスクの起動を意味しない。運用の登録・実行は実際のタスクと履歴で確認し、定義だけで稼働済みと扱わない。

## 現在のグロース・SEO連携

本人の「提案にとどまらず、自動で日々サイトを良くする」という2026-11-02の指示に基づき、[公開済みページの日次改善](../automation/growth-seo/README.md)を進める。統括秘書が進行し、グロースがデータ品質・問い合わせ導線・実験、SEOが検索意図・内部リンク・技術SEO、よっしーAIが既存事業判断基準を確認する。

通常の許可範囲は分析だけで終わらず、PR・CI・差分確認・merge・本番確認・効果確認まで進める。変更は最大1仮説・欠陥/日とし、不要な改稿は行わない。独立レビューを優先し、別エージェント機能がない場合は低リスク範囲で第二パスを実行して `same_actor_separate_passes` と記録する。17役すべてが独立常駐する運用ではない。実数値・レビュー・実験履歴は認可済みPrivate領域に保存し、結果は09:00朝会へ集約する。

名簿の `newRoleRuntime` は役割追加当初の標準権限を表す。今回の限定運用は別の `growthSeoCycle` からpolicyを参照し、全役の外部操作権限を一括で変更しない。既存の公開前原稿、営業送信、価格・契約・支出・権限は従来の承認範囲を維持する。

## 呼び出し例

以下は自然言語の依頼例であり、新しいアプリ内コマンドや自動送信機能ではない。

| 呼び方 | 依頼例 |
|---|---|
| 営業 | 「承認済みのターゲット方針から、見込み企業を5社調査して個別提案を下書き。送信しない」 |
| 見積 | 「この匿名化した相談の不足条件と工数を整理し、3案を比較。価格確定・送信はしない」 |
| PM | 「確定要件から初稿・顧客確認・修正・納品準備の工程案を作って」 |
| グロース | 「取得済みの流入・CTA・問い合わせを区別し、SEOと連携して許可範囲の改善を1つ実装・検証・観測して」 |
| クリエイティブ | 「この許諾済みブリーフからコンセプト・顔固定条件・ショット表・品質基準を作って」 |
| 権利 | 「この案件の人物・音声・音楽・ロゴ・AI入力に関する確認漏れを整理して」 |
| 財務 | 「認可済みの実績データから、案件別粗利と内部工数控除後の採算を分けて」 |

## 起動時の手順

[共通運用](../AGENTS.md) → [事業チームルーター](../secretary/business-team-router.md) → 対象役割定義 → [共通タスク様式](../tasks/business-task-template.md) の順に読む。必要な正本・認可済みデータを確認してから作業する。欠けた項目を推測しない。

新設7役の標準はオンデマンド。公開済みページの日次改善は上記の別途明示承認済み運用に従う。定期実行、Apollo・メール・GA4・会計・生成動画ツールの新規接続、実案件保存先の構築はこの追加に含めない。実際の接続を読み取りで確認できていない機能は「未接続／未確認」とする。

## 役割追加当初のタスク候補（実行証拠は別途確認）

まず営業のターゲット確認、見積の共通ヒアリング票、PMの工程テンプレートを作る。グロースは計測源の棚卸し、クリエイティブは品質基準、権利は許諾確認票、財務は案件採算の入力項目を整える。これらは開始提案であって、依頼・実行・成果物完成の記録ではない。

## 検証

`python3 scripts/check-ai-team.py` で名簿・役割ファイル・内部リンク・共通安全設定を検査する。`python3 -m unittest discover -s scripts -p 'test_ai_team.py'` で異常系も検証する。これらは文書構造の検査であり、モデルの性能・独立稼働・外部API接続のテストではない。

## よっしーAIの起動

「よっしーAIで判断して」で判断基準レビューを依頼できる。[判断基準](../leadership/yossy-decision-profile.md)と[内部PDCA](../secretary/yossy-pdca.md)を読み、秘書経由で内部修正を回す。本人承認は代行しない。定期タスクの実行時読込は別途確認する。
