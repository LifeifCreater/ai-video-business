# FRAMEPACT AIチーム — 16の役割定義

更新日: 2026-09-17。既存9役に、営業から利益管理までを担当する7役を追加する。名簿の正本は [team-register.json](team-register.json)。これは役割プロンプトの構成であり、16個の独立したAIや常駐タスクの起動を意味しない。mainへの取り込み前は追加提案として扱う。

最終決定はよっしー。依頼窓口は統括秘書のままとし、AI COOは判断案、新設各役はその範囲内の下書き・分析を担当する。PMは顧客案件の工程、統括秘書はチーム全体の進行を担当し、互いに承認を代行しない。

## 呼び出し例

以下は自然言語の依頼例であり、新しいアプリ内コマンドや自動送信機能ではない。

| 呼び方 | 依頼例 |
|---|---|
| 営業 | 「承認済みのターゲット方針から、見込み企業を5社調査して個別提案を下書き。送信しない」 |
| 見積 | 「この匿名化した相談の不足条件と工数を整理し、3案を比較。価格確定・送信はしない」 |
| PM | 「確定要件から初稿・顧客確認・修正・納品準備の工程案を作って」 |
| グロース | 「取得できている流入・CTA・問い合わせを区別して、改善実験を1つ提案して」 |
| クリエイティブ | 「この許諾済みブリーフからコンセプト・顔固定条件・ショット表・品質基準を作って」 |
| 権利 | 「この案件の人物・音声・音楽・ロゴ・AI入力に関する確認漏れを整理して」 |
| 財務 | 「認可済みの実績データから、案件別粗利と内部工数控除後の採算を分けて」 |

## 起動時の手順

[共通運用](../AGENTS.md) → [事業チームルーター](../secretary/business-team-router.md) → 対象役割定義 → [共通タスク様式](../tasks/business-task-template.md) の順に読む。必要な正本・認可済みデータを確認してから作業する。欠けた項目を推測しない。

新設7役はすべてオンデマンド。定期実行、Apollo・メール・GA4・会計・生成動画ツールの新規接続、実案件保存先の構築はこの追加に含めない。実際の接続を読み取りで確認できていない機能は「未接続／未確認」とする。

## 初回タスク候補（未着手・未予約）

まず営業のターゲット確認、見積の共通ヒアリング票、PMの工程テンプレートを作る。グロースは計測源の棚卸し、クリエイティブは品質基準、権利は許諾確認票、財務は案件採算の入力項目を整える。これらは開始提案であって、依頼・実行・成果物完成の記録ではない。

## 検証

`python3 scripts/check-ai-team.py` で名簿・役割ファイル・内部リンク・共通安全設定を検査する。`python3 -m unittest discover -s scripts -p 'test_ai_team.py'` で異常系も検証する。これらは文書構造の検査であり、モデルの性能・独立稼働・外部API接続のテストではない。
