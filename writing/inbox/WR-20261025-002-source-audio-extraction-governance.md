## description案
動画の音声トラックを分離・移動・差し替える前に、原音保存、話者、利用目的、前後の文脈、映像との同期、公開版の承認を整理するチェック表を紹介。

---

イベントのダイジェストやインタビュー動画を編集するとき、「声だけを別の場面で使いたい」「一部の音を消したい」「ナレーションを差し替えたい」と考えることがあります。

映像と音声を別のトラックにすれば、編集の自由度は上がります。しかし、**音声を切り離せることと、その音声を別の場面で使ってよいことは別**です。

音声だけを別場面へ移した結果、話者の発言が違う意味に聞こえたり、拍手のタイミングが実際の映像と合わなくなったりすることもあります。この記事では、収録済みの動画素材から音声を分離した後の「原音・用途・場面・版」の管理方法を整理します。

## 新しい音声抽出機能と、企業動画で必要な確認は別

2026年10月23日、GoogleはGoogle Vidsで動画クリップの音声を独立したトラックとして抽出できる機能を発表しました。分離した音声は、元映像とは別にトリミング、移動、削除でき、複数シーンにまたがる配置も可能だと説明しています。段階提供は10月19日からです。

これは**動画に含まれる音声トラックを独立して編集する機能**の説明です。声を完全に復元すること、BGMと声を自動で分けること、録音や二次利用の許諾が得られていることを意味しません。対応アカウントや細かな出力挙動は利用環境で確認してください。

## 1. 元動画・原音・編集版・公開版を分けて保管する

編集前に、どのファイルを基準にするのか決めます。

- **元動画**：撮影・収録時の映像と音声を保持する基準ファイル
- **抽出した原音**：元動画のどの区間から取り出したか追跡できる音声
- **編集作業版**：移動、無音化、音量調整、差し替えなどを試す版
- **確認版／公開版**：担当者が確認する書き出しと、最終採用する版

元動画を上書きすると、後から発言の前後を確かめにくくなります。素材ID、元動画、抽出区間、編集内容、版番号を対応させましょう。

保管先、アクセス権、保存期間は、案件の契約・社内規程・素材の性質に応じて決めます。

## 2. 音声を使う目的と話者・場面を確認する

音声を分離した後、「できる編集」からではなく「必要な編集」を選びます。

- 雑音が気になるので、該当区間の音量や使用範囲を調整する
- インタビューの冒頭発言を、同じ内容を説明する場面へ移す
- 会場音を短く残し、別途用意したナレーションを追加する
- 長い無音区間を整理し、発言とカットの対応を維持する

それぞれ、どの場面で何を伝えたいかを確認します。特に登壇者、社員、インタビュー対象者の発言は、前後の会話や質問と切り離すことで意味が変わらないか注意が必要です。

**編集許可と公開利用の確認先は別になり得ます。** 収録時の同意や契約で許される利用範囲を把握できていなければ、使用可能と断定せず確認事項として残します。

## 3. 映像と音声のタイミングを再確認する

音声が分離できても、移動後に映像と合っているとは限りません。次の点を確認します。

- 話者の口元と発言内容が不自然にずれていないか
- 発言の主語、否定、条件が前後の映像に対応しているか
- 拍手、歓声、ドアの開閉などの音が場面に合っているか
- 製品操作やデモンストレーションの説明が、実際の操作を指しているか
- ナレーション、会場音、BGMを重ねたときに必要な発話が聞き取れるか
- 字幕と音声の内容・表示タイミングが一致するか

音量調整だけなら許容できる場面でも、別の映像へ発言を移すと文脈の再確認が必要になることがあります。**音が自然であることと、説明が正確であることを分ける**のがポイントです。

## 4. 変更した理由と判断担当を残す

編集作業版だけを渡すと、確認者は「どこを変えたのか」を見落とす可能性があります。用途を区切った短い確認表を作りましょう。

| 確認項目 | 記入すること |
|---|---|
| 素材ID・原音版 | 元動画と抽出した音声を照合できるID |
| 話者・収録場面 | 誰の、どの場面の音声か |
| 編集目的 | 聞き取り改善／差し替え／構成変更など |
| 変更内容 | 移動／削除／無音化／音量調整など |
| 使用先の場面 | どの映像・どの目的に使うか |
| 同期確認 | 口元、動作、字幕、環境音との対応 |
| 利用範囲の確認先 | 収録同意・契約・社内規程の担当者 |
| 判断者 | 編集担当、内容責任者、公開責任者 |
| 採用する公開版 | 版番号、確認日、未解決事項 |

**架空の例**：社内イベントの開会あいさつ「音声E-02」を短く編集。前後の説明を切ると発言の対象が分かりにくくなるため、元の映像を残す案と、補足字幕を入れる案を並べ、イベント担当者が採否を判断する。

これは記入方法を示した仮例であり、実在イベントや顧客の実績ではありません。

## 5. 音声の品質確認と、利用・公開の承認を分ける

社内で確認するなら、次のように役割を分けると判断が明確になります。

- **編集担当**：音のつながり、音量、映像・字幕との同期を確認
- **内容責任者**：発言の意味、数値、固有名詞、文脈を確認
- **素材・権利の確認担当**：収録時の合意、利用目的、公開範囲を確認
- **公開責任者**：採用版、残存する懸念、公開可否を判断

「編集が完了した」という報告だけで、発言の内容や公開範囲まで承認済みとは扱いません。確認に使ったファイルの版番号を残しておくことも大切です。

## 6. 公開前に、音声・字幕・映像を一緒に確認する

音声ファイル単体では問題がなくても、字幕や映像と組み合わせた最終版で意味が変わる場合があります。

公開前に、最終版を通して、発言の内容、字幕、ナレーション、会場音、映像、クレジットを確認します。意図しない発言の切り取り、必要な許諾の不足、説明と映像の不一致が残るときは、修正、原音採用、再収録、該当箇所の使用見送りも選択肢です。

## 音声を分離する前に「何を残すか」を決める

企業動画の音声編集で重要なのは、編集ツールの機能だけではありません。**元の発言に戻れること、変更した理由が分かること、利用する場面と公開版を確認できること**が、安心して制作を進めるための基盤になります。

FRAMEPACTでは、企業・法人・団体向けのイベント動画制作に対応しています。生成AIを活用する場合も案件ごとに使用範囲を調整し、人が編集、構成調整、テロップ、音声、品質確認を行います。

**イベントやインタビューの素材をどう編集・構成すべきか迷っている場合は、[FRAMEPACTのイベント動画制作](https://framepact.jp/event-video.html)からご相談ください。**
