# マニュアルを動画化する前に｜原稿・省略・更新の決め方

## description

マニュアルや説明資料を動画化する前に、正本文書の版、残す内容、省略条件、台本照合、確認担当、文書改訂時の更新方法を整理する実務手順と照合表を紹介します。

---

マニュアルや説明資料を動画へ変えるとき、文章を短くして読み上げるだけでは、元の意味を保てないことがあります。

条件、例外、否定、手順の順番などが省略されると、映像としては分かりやすくても、業務上必要な情報が抜ける可能性があります。一方で、文書の全内容をそのまま詰め込むと、何を理解してほしい動画なのかが伝わりにくくなります。

制作を始める前に「何を正本にするか」「何を必ず残すか」「誰が内容を確認するか」「文書が変わったら動画をどう更新するか」を決めておくことが大切です。

## 1. 使用する文書の版と利用範囲を決める

最初に、動画の根拠にする文書を一つに定めます。

- 文書名と管理番号
- 版番号または改訂日
- 管理部署
- 対象となる業務や利用者
- 動画化してよい範囲
- 参照だけに使う資料
- 使用しない旧版

複数の資料で内容が異なる場合は、制作側の判断だけで統合せず、文書の管理担当者へ確認します。

また、社内限定資料、個人情報、第三者から提供された情報などを外部の制作会社やサービスへ共有できるとは限りません。社内ルールや利用条件を確認し、制作に必要な範囲だけを渡せないか検討します。

## 2. 視聴者と視聴目的を決める

同じマニュアルでも、初めて業務を行う人と、変更点だけ確認する人では必要な説明が異なります。

制作前に、次の内容を一文で整理します。

- 誰が見るのか
- どの場面で見るのか
- 視聴前に何を知っている想定か
- 視聴後に何を理解・実行してほしいか
- 動画だけで完結させるか、文書も併用するか

動画の目的を決めると、残す情報と補足資料へ分ける情報を判断しやすくなります。

## 3. 必ず残す内容と、補足へ分ける内容を整理する

要約する前に、省略してはいけない内容を先に示します。

特に確認したいのは、次のような情報です。

- 適用条件と対象外
- 例外処理
- 禁止事項
- 注意事項
- 数値、期限、固有名詞
- 手順の順番
- 前後の工程との関係
- 問い合わせ先や判断者

一方、背景説明、詳細な参考情報、関連資料の全文などは、動画内へ詰め込まず補足資料へ案内できる場合があります。

「短くするために削る」のではなく、視聴目的と業務上の重要性に基づいて分けます。

## 4. 見出しを台本・ナレーション・画面説明へ展開する

文書の文章を、そのままナレーションへ置き換える必要はありません。

各見出しについて、次の役割へ分けて整理します。

- ナレーションで説明する内容
- 画面上の字幕として残す内容
- 図や操作画面で見せる内容
- 注意喚起として強調する内容
- 文書や補足資料へ案内する内容

ナレーションだけで重要事項を伝えると、聞き逃した際に確認しにくくなることがあります。数値、条件、手順名などは、字幕や図解でも確認できる形を検討します。

## 5. 原文と台本を項目ごとに照合する

台本ができたら、読みやすさだけでなく、元の意味が変わっていないかを確認します。

特に次の項目は、原文の該当箇所と並べて確認します。

- 数値と単位
- 固有名詞
- 「しない」「できない」などの否定
- 「場合」「ただし」などの条件・例外
- 手順の順番
- 対象者と対象外
- 期限や更新日
- 問い合わせ・判断の担当

言い換えによって断定の強さが変わっていないか、条件が一般化されていないかも確認します。

AIを台本や素材制作へ使う場合も、生成結果だけで原稿の正しさを確定せず、原文と照合できる状態を残します。

## 6. 内容の責任者と映像表現の確認担当を分ける

一人がすべてを確認するのではなく、確認対象を分けます。

### 業務内容の責任者

- 原文との一致
- 条件・例外・手順
- 数値や固有名詞
- 現行ルールとの整合

### 映像表現の確認担当

- 字幕や図解の読みやすさ
- ナレーションと画面の対応
- 誤解を招く表現の有無
- ブランド表現
- 音声、色味、画面構成

最後に、どの版を公開できるか判断する担当者も明確にします。映像が完成していることと、内容が承認済みであることを同じ扱いにしません。

## 7. 文書改訂時に動画を更新する条件を決める

動画を公開した後に元の文書が改訂されることがあります。

制作前に、次の運用を決めます。

- 文書と動画の版を対応させる方法
- 改訂を動画担当者へ知らせる人
- 更新が必要になる変更条件
- 一部修正でよい範囲
- 全体確認をやり直す範囲
- 旧版動画の使用停止と保管
- 更新後の公開先確認

生成した動画を規程や正式通知そのものの代わりにせず、どの正本文書に基づく動画なのかを追えるようにします。

## 8. 制作会社へ渡す照合表を作る

外注前に、正本と動画原稿の関係を一つの表へまとめます。

| 項目 | 記入内容 |
|---|---|
| 正本の版 | 文書名、管理番号、版番号、改訂日 |
| 該当箇所 | 元文書の見出し、ページ、段落 |
| 台本の該当行 | 対応する台本・ナレーション |
| 残す意味 | 視聴者へ必ず伝える内容 |
| 省略した内容 | 動画外へ分けた内容と理由 |
| 字幕・図解 | 画面に残す数値、条件、手順 |
| 確認者 | 内容、表現、公開の各担当 |
| 更新条件 | 文書改訂時に見直す条件 |

この表は空のひな型として使い、顧客資料、社内規程、個人情報を不用意に転記しないようにします。

## 動画化の前に、正本と確認方法をそろえる

元資料の内容が多い段階でも、対象者、視聴目的、必ず残す内容、確認担当を整理すれば、動画にする範囲を検討できます。

FRAMEPACTは、企業・法人・団体向けの研修・教育動画に対応しています。生成AIを活用する場合も出力をそのまま納品せず、人が編集、構成調整、テロップ、音声、色味、品質確認を行い、使用範囲は案件ごとに調整します。

マニュアルや説明資料を、どこまで動画へ含めるか整理したい方は、[FRAMEPACTの研修・教育動画制作](https://framepact.jp/training-video.html)からご相談ください。
