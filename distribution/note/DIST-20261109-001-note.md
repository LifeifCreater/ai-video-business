# note展開候補：生成AI動画の「新機能」を本番制作へ入れる前に決めたいこと

- source: WR-20261108-001
- approvalStatus: owner_review
- publishStatus: unpublished
- postingMode: owner_manual

生成AI動画の新機能を見つけると、次の企画ですぐ試したくなります。ただ、公式に発表されたこと、自社のアカウントで機能が見えること、企業案件で安定して使えることは別です。

公開後にロールアウトが止まることもあります。契約や管理者設定によって使える人が変わることもあります。生成できる尺、解像度、画面比率が納品条件に合わないこともあります。

だから構成を確定する前に、提供状態、対象契約、地域、管理者設定、検証アカウント、確認日時、出力条件を記録します。判断は「採用」「条件付き採用」「代替」「保留」に分けます。確認できない事項を推測で埋めないことも重要です。

そして、新機能が止まった場合の代替手段を先に決めます。既存素材、追加撮影、ストック、図解、テキストアニメーションなどへ切り替えても、動画の目的と主要メッセージを保てるかを確認します。

新しい機能を使うこと自体が目的ではありません。企業動画では、誰が・どの環境で・いつ確認し、使えない場合にどう戻るかまで設計しておくことが、後戻りを減らします。
