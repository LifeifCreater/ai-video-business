## 構成案

- 導入: 展示会・イベントの撮影映像では、会場で気づかなかった映り込みが編集段階で見つかる。しかし、消せるものをすべて消すと、商品、表示、会場の事実まで変えるおそれがある
1. 削除候補を、撮影機材、通行人、他社表示、反射・影、商品・安全表示に分類する
2. 「見栄えの整理」「公開範囲への配慮」「事実を変える可能性」を分け、削除理由と判断者を決める
3. 未加工原本を保持し、クリップIDとタイムコードで削除対象を指定する
4. 外部AI・クラウドへ入力できる素材か、人物・顧客・会場情報を含めて確認する
5. マスク、トラッキング、影、反射、遮蔽、前後フレーム、境界の不自然さを全区間で確認する
6. 元版、生成版、再生成版、採用版を対応させ、何を削除したかを最終確認者へ渡す
7. 展示会会場で使用するモニター、再生距離、ループ再生を想定して加工跡と残すべき表示を確認する。別媒体へ転用する場合は媒体別の確認工程へ引き継ぐ
- 成果物案: 空欄の映り込み削除確認表（クリップID / タイムコード / 削除対象 / 削除理由 / 残すべき情報 / 入力可否 / 原本保管先 / 加工版 / 影・反射・境界確認 / 利用先 / 確認者 / 判断 / 再確認期限）
- 記入例: 架空の展示会ブース紹介動画。実在会場、企業、人物、商品、顧客素材は使わない
