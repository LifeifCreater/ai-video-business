## 構成案

- 導入: 「短く見せる」ための速度変更で、説明の意味まで変わっていないか
1. 個別クリップの速度を変えられる公式機能例と、対象版・提供時期を短く紹介する
2. 速度変更の目的を、待ち時間の短縮、手順の強調、尺調整に分ける
3. 手順・指差し・画面操作・注視時間が追えるかを確認する
4. 元音声、差し替えナレーション、字幕、効果音の同期を変更後の版で確認する
5. 数値、警告、免責、社名・商品名など、短縮してはいけない表示を分ける
6. 空欄の確認表を示す: クリップID / 元の長さ / 変更速度 / 目的 / 内容の欠落 / 音声・字幕同期 / 注意表示 / 判断者 / 採否
7. 元版と変更版を残し、用途別の納品版・公開版を取り違えない
- 見出し案: 「速くしてよい間と、速くしてはいけない説明」「変更後の版で字幕と操作を見直す」
- 成果物案: 空欄の速度変更確認表と、架空の操作説明動画による短い記入例。理解度・成果の数値は作らない
