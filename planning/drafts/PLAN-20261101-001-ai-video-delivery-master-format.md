## 記事で答える問い

1. レビュー用、再編集用、保管用、公開用で、納品ファイルを分ける必要があるのはなぜか
2. 解像度以外に、コンテナ、ビットレート、フレームレート、色、音声、容量をどう確認するか
3. 軽量な確認版と高品質マスターをどう区別し、正本をどう示すか
4. 受け入れ時に再生、尺、音、字幕、ロゴ、ファイル破損、版番号をどう確認するか
5. 使用先の上限や互換性を、発注前と納品前のどちらで確認するか

## 推奨構成

### 1. 同じ1080pでも納品品質は同じとは限らない

解像度だけでは圧縮の程度、色の扱い、編集耐性、ファイル容量、音声仕様、互換性を判断できないことを説明する。特定ツールの仕様を一般則に広げず、納品先と再編集環境での実機確認を前提にする。

### 2. 最初に用途を4つに分ける

- レビュー用: 軽量で共有しやすく、内容確認を優先
- 再編集用: 編集ソフトで扱えることと、再圧縮に耐える余地を優先
- 保管用: 正本、版、保持期間、復元方法を明確化
- 公開用: 配信先の上限、比率、容量、音声、字幕要件に合わせる

### 3. マスターと確認版を分ける

マスター、軽量確認版、公開先別書き出しを同じ「納品物」として混同しない。ファイル名、版番号、作成日、用途、正本フラグ、置き場所をそろえる。

### 4. 発注書・受け入れ表に入れる仕様

| 項目 | 確認内容 |
|---|---|
| 用途 | レビュー、再編集、保管、公開 |
| ファイル形式 | コンテナ、拡張子、再生・編集環境 |
| 映像 | 解像度、比率、フレームレート、ビットレート |
| 色 | 色の見え方、変換有無、確認環境 |
| 音声 | 有無、チャンネル、音量、言語、無音区間 |
| 容量 | 1ファイルと一式の上限、転送方法 |
| 版管理 | ファイル名、版番号、正本、差し替え履歴 |
| 受け入れ | 再生、尺、音、字幕、ロゴ、破損、末尾までの確認 |
| 予備対応 | 再書き出し条件、互換形式、連絡先 |

### 5. 画質・容量・編集用途のトレードオフを確認する

高いビットレートや編集向け形式は、細部保持や後工程に有利な場合がある一方、容量、転送時間、再生互換性とのトレードオフがある。仕様値を固定的な推奨値として断定せず、使用先と制作環境から決める。

### 6. 公開先・保管先の制約を先に照合する

公開プラットフォーム、社内ストレージ、メール、チャット、レビューサービス、編集ソフトの制約を列挙し、最も厳しい制約だけに全納品物を合わせない。必要なら用途別に書き出す。

### 7. 納品完了を受け入れ確認で閉じる

ファイルが届いたことと納品完了を分ける。指定環境での再生、冒頭から末尾、音声、字幕、ロゴ、版、破損、ファイル数を確認し、問題時の再書き出し条件を決める。
