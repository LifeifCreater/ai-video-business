## 企画設計

- 主要メッセージ: 動画の完成尺、完成カット数、候補として作る生成案数、修正で行う再生成、最終出力は別の単位である。見積もり前に用途・必要尺・案数・確認時点・受入条件を分けると、比較と相談がしやすくなる
- 独自性: 一般的なAI動画の料金相場や特定ツールのAPI説明ではなく、発注側が「何を何案確認し、どの時点で確定し、どこから再見積もりか」を整理する実務記事に限定する
- FRAMEPACTが発信する理由: `business/framepact-service-facts.md` では、生成カット上限、編集修正2回、部分再生成1回、確定後の企画変更・上限超過は別見積もりという条件が承認済み。用途・尺・案数・修正条件を持った具体的な相談へ自然につなげられる

## 構成案

- 導入: 同じ30秒の動画でも、完成に使う生成尺と、候補比較や作り直しで発生する生成工程は同じとは限らない
1. 完成尺、完成カット数、生成案数、再生成、最終出力を分ける
2. 用途と品質基準から、必要なカットと確認者を決める
3. 1カットあたり何案を比較するか、候補案を増やす条件を決める
4. ラフ確認、構成確定、完成確認のどこで判断するかを決める
5. 編集修正と部分再生成、企画変更を分ける
6. 解像度・比率・音声・参照素材の変更が見積条件へ与える影響を確認する
7. 見積書と発注時に、基本範囲、上限、追加見積もり条件、判断者を残す
- 成果物案: 空欄の見積条件確認表（用途 / 完成尺 / 完成カット数 / 生成案数 / ラフ確認 / 確定時点 / 編集修正 / 部分再生成 / 企画変更 / 比率・解像度 / 音声 / 参照素材 / 受入条件 / 判断者 / 追加見積もり条件）
- 記入例: 架空の30秒商品紹介動画。実在顧客、案件、社内原価、実測効果は使わない
