# 事業施策の意思決定フレームワーク

## 評価方法

各軸を `1（弱い・不利）`〜`5（強い・有利）` で評価し、根拠を添える。情報不足は点数を推測せず `未評価` とする。点数は判断補助であり、自動承認には使わない。

| 評価軸 | 確認する問い | 配点 |
|---|---|---:|
| 事業目標との整合性 | 直接受注、相談、信頼、効率のどれに寄与するか | 1–5 |
| 顧客課題の強さ | 頻度、深刻度、支払意思があるか | 1–5 |
| 需要の根拠 | 一次情報、相談、検索、販売実績などがあるか | 1–5 |
| FRAMEPACTの強みとの一致 | 広報、YouTube、編集、生成AI、企業理解を活かせるか | 1–5 |
| 売上への期待 | 売上への経路と規模が説明できるか | 1–5 |
| 問い合わせ獲得への期待 | 相談につながる対象・導線があるか | 1–5 |
| ブランド価値への影響 | 信頼と先進性を高めるか、情報商材感を生まないか | 1–5 |
| 実行コスト | 必要予算に対して実行可能か | 1–5（低コストほど高得点） |
| 必要時間 | オーナーの稼働内で実行できるか | 1–5（短いほど高得点） |
| 法務・規約・信用リスク | リスクが把握・管理可能か | 1–5（低リスクほど高得点） |
| 再利用性 | 複数媒体・営業・商品で再利用できるか | 1–5 |
| 検証しやすさ | 短期間に測定可能な結果が得られるか | 1–5 |
| 他施策との相乗効果 | サイト、X、コラム、Tips、営業をつなぐか | 1–5 |
| 今やる必要性 | 期限、機会、市場変化があるか | 1–5 |
| 今やらない場合の影響 | 機会損失、信用、学習遅延が大きいか | 1–5 |

## 分類

- **今すぐ実行候補**: 根拠、実行可能性、期待効果が高く、重大リスクが整理済み
- **小規模テスト候補**: 仮説に不確実性はあるが、低コスト・短期間で検証可能
- **追加調査が必要**: 需要、顧客、価格、規約など重要情報が不足
- **将来候補**: 価値はあるが、時期、資源、依存関係のため今は優先しない
- **見送り**: 目標不整合、弱い需要、高リスク、過大工数、重複などが明確

## 必須ゲート

次のいずれかが未整理なら実行候補にしない: 対象顧客、需要根拠、ブランド整合、必要時間、予算、重大リスク、KPI、検証期限、撤退条件、オーナー判断事項。
