# よっしーの事業判断基準 v1

2026-10-03。事業運用用の公開可能な方針だけを収録する。人格の完全な再現・モデル学習済みという意味ではない。最新の本人指示を優先し、料金と実績は各正本を読む。

## 確定方針

根拠: [全担当共通方針](../AGENTS.md)（2026-09-17）、[意思決定フレームワーク](decision-framework.md)、[ブランド](../brand/brand-guidelines.md)。

| 判断軸 | 採用方向 | 差し戻す方向 |
|---|---|---|
| 本人の稼働と採算 | 高付加価値の直接提案。打合せから納品・外注管理まで評価 | 売上だけで採算を判断。低単価の量産編集を中心にする |
| 成長の仕組み | 標準化・自動化・再利用。件数に比例する本人稼働を減らす | 本人の手作業を増やすだけの受注拡大 |
| 顧客価値 | 企業の課題と目的に対する企画・演出・品質 | AIツールの名前や安さだけを価値として扱う |
| 集客 | 有効な相談・購入への導線と検証 | 閲覧数・記事本数だけを成果にする |
| 信頼と品質 | 正本と根拠、ブランド一貫性、レビュー可能な成果物 | 誇張、未確認実績、非公開情報の転記 |
| 進め方 | 主担当を絞り、完成した成果物と推奨を提示 | 全担当を毎回通す、仮想会議だけで実行済みにする |

## 仮説と未設定

「迷う案は小さく検証し、オーナーの確認負担を減らす」を初期運用仮説とする。本人から訂正があれば更新する。最低受注額、最低実質時給、許容工数、広告予算、売上目標、評価軸の重みをこの役割は新たに確定しない。

## 判断・更新の扱い

- 重要な未取得値を架空の点数で補わず、確認または小規模検証へ回す。
- 適合の推奨は `recommend / revise / investigate / hold / reject`。オーナー承認とは別項目にする。
- 最新指示が過去方針と矛盾する場合は対象範囲と変更点を記録する。外部操作の包括承認へ拡張しない。
- 方針変更には根拠・日付・旧方針・新方針・本人確認を付ける。AI推測と本人の発言を混ぜない。
- 営業送信停止と既存公開承認フローを維持する。
