# FRAMEPACT コンテンツ品質チェック

## 使い方

成果物ごとに本チェックを複製するか、タスクファイルの品質確認欄から参照する。各項目を `合格 / 要修正 / 要確認 / 対象外` で判定し、根拠または修正内容を記録する。`要修正` が1つでも残る成果物はレビュー依頼しない。`要確認` はオーナーが判断できるよう明示する。

## 必須チェック

### 1. 事実確認

- [ ] FRAMEPACTの料金、納期、修正条件、権利、サービス範囲を `business/framepact-service-facts.md` と照合した
- [ ] 実績、経歴、顧客事例を `business/public-experience-facts.md` と照合した
- [ ] 正本で未承認・オーナー確認待ちの情報を断定していない
- [ ] 外部情報は `research/verified/` の `verified・有効` だけを使用している
- [ ] verifiedの再確認期限が切れていない
- [ ] 担当AIが正本・verifiedにない事実を補完していない
- [ ] サービス内容、実績、数値、固有名詞、日付、料金、仕様に根拠がある
- [ ] 変化し得る情報は公開前時点の一次情報で確認している
- [ ] 引用・参考情報の出典と確認日を記録している
- [ ] 推測、意見、事実が読み手に区別できる
- 判定・メモ:

### 2. 誇大表現の有無

- [ ] 「必ず」「絶対」「業界初」「No.1」など、証明できない断定を使っていない
- [ ] AI動画の品質、速度、費用、成果を過度に保証していない
- [ ] 比較表現や数値効果に適切な条件・根拠がある
- 判定・メモ:

### 3. FRAMEPACTらしい内容か

- [ ] 生成AIを目的ではなく、企業の課題を解決する手段として扱っている
- [ ] 「企業の想いを、伝わり行動につながる映像へ」という方向性と整合する
- [ ] 派手さや煽りより、具体性、誠実さ、実用性を優先している
- [ ] `brand/` 配下の各方針に反していない
- 判定・メモ:

### 4. 企業向けの信頼感があるか

- [ ] 企業担当者の課題、判断材料、導入上の懸念に応えている
- [ ] できることと難しいこと、条件や限界を明確にしている
- [ ] 幼すぎる表現、過度な煽り、根拠のない権威付けがない
- [ ] 読み手が次の行動を安心して選べる
- 判定・メモ:

### 5. AIが書いたような不自然な文章になっていないか

- [ ] 抽象語、同義反復、過剰な箇条書き、紋切り型の結論が続いていない
- [ ] 「〜と言えるでしょう」「いかがでしたか」などの不要な定型句を避けている
- [ ] 文の長短、語尾、接続が自然で、音読して違和感がない
- [ ] 具体例やFRAMEPACT固有の視点があり、誰にでも当てはまる文章だけになっていない
- 判定・メモ:

### 6. 既存コンテンツと重複していないか

- [ ] `content/`、`tasks/`、公開済みサイトを検索した
- [ ] 同一テーマでも、読者、切り口、提供価値、CTAのいずれかに明確な違いがある
- [ ] 類似コンテンツがある場合、統合、更新、再編集の方が適切でないか検討した
- [ ] 確認した類似コンテンツを記録した
- 判定・類似コンテンツ:

### 7. 適切なCTAがあるか

- [ ] 目的に対応するCTAが1つに絞られている
- [ ] 読者の検討段階に対して行動のハードルが高すぎない
- [ ] CTAの遷移先、表現、前後の文脈が一致している
- [ ] 押し売りではなく、読者にとっての次の価値が明確
- 判定・CTA:

### 8. 公開してはいけない個人情報や顧客情報が含まれていないか

- [ ] 氏名、連絡先、所属、顔、位置情報などの個人情報を無断で含めていない
- [ ] 顧客名、案件内容、契約、金額、社内情報、未公開実績を無断で含めていない
- [ ] ファイル名、画像、メタデータ、リンク先にも機密情報がない
- [ ] 掲載許諾の範囲と公開先が一致している
- 判定・メモ:

## 追加チェック

## SEOレビュー・実装前チェック

- [ ] 検索意図と対象読者の課題が一致している
- [ ] title、H1と本文の内容が一致している
- [ ] H1、H2、H3の階層と各見出しの役割が適切である
- [ ] 既存記事との重複・カニバリゼーションを確認した
- [ ] 読者の次の疑問に役立つ内部リンク候補がある
- [ ] キーワードを不自然に反復していない
- [ ] 検索ボリューム、順位、流入などを根拠なく断定していない
- [ ] サービスページ・相談への誘導が検索意図から自然につながる

- [ ] Article、BlogPosting、BreadcrumbListなど構造化データの要否を確認する

- [ ] 元企画または元原稿がオーナー承認済みである
