# 新設事業チームの成果物と保存先

このPublicリポジトリには運用定義と空テンプレートを置く。Private情報はブランチを変えても安全にはならない。顧客の見積・契約・素材、営業先リスト・連絡先・返信、案件利益・原価・請求・口座・個人資産は保存しない。

## Private出力の配置案

オーナーが認可したPrivateリポジトリまたはPrivateストレージを `privateOutputRoot` として別途指定する。この追加では作成・接続・既存資産リポジトリへの転用をしない。

```text
<認可済みPrivate領域>/
  sales/        営業候補・接触記録・未送信提案
  estimates/    要件・積算・顧客向け見積案
  production/   工程・素材・修正・納品準備
  growth/       非公開計測・匿名集計・実験案
  creative/     許諾済みブリーフ・参照・ショット表
  rights/       許諾記録・契約論点・確認票
  finance/      案件採算・入出金見通し
```

保存前に閲覧者・保存対象・保持期間・案件間の分離を確認する。対応表やPrivate参照URLもPublicへ自動転記しない。Publicで必要な場合はオーナーが公開を認めた匿名IDと非機密の進捗だけにする。

`privateOutputRoot` がnullの間は、実データの永続保存を停止する。一般的な設計や架空サンプルの作成は継続できるが、サンプルを実績やKPIへ入れない。

## 共通フォーマット

[事業タスク様式](../../tasks/business-task-template.md)と各担当定義を使う。Publicへの保存が必要な匿名化資料は、匿名化の確認だけでなく公開承認を別途得る。既存の資産・編集部・Search Consoleの実行台帳に事業チームの実データを混ぜない。
